# Headings — default rules

## Headings

| ID | Rule | Source | Weight | Status | Unblock requirement |
|---|---|---|---|---|---|
| HEAD-001 | Each page has exactly one `<h1>`. | SEO fundamentals | 4 | open | — |
| HEAD-002 | No page uses a bare numeral (e.g. a step-counter "1", "2", "3") as a heading. | SEO fundamentals | 3 | open | — |
| HEAD-003 | Each page has at least one `<h2>`. | SEO fundamentals | 2 | open | — |
| HEAD-004 | No page skips a heading level (e.g. an `<h3>` before any `<h2>`). | Accessibility / SEO fundamentals | 2 | open | — |
