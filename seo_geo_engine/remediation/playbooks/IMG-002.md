# IMG-002 — Every image on every page has alt text.

**Rule:** Every image on every page has alt text.

**Evidence the check emits:** Pages whose `imagesMissingAlt` is greater than 0.

**Kind of change that flips it:** Write alt text that describes the image. Empty `alt=""` is for decorative images; the check treats empty as missing, so genuinely decorative images need a different approach (CSS background, or a profile override with a reason).

**Depends on:** `CMS-ACCESS`

Fix the image block / media library field. Do not set `alt` to the filename.

Apply the change in the site's own repo or CMS. Re-crawl, confirm the
verdict flipped, then run `seo-geo-plan-sync` so the row is deleted.
Do not hand-edit a generated report.
