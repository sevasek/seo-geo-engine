# OG-002 — Every page has a non-empty `og:description`.

**Rule:** Every page has a non-empty `og:description`.

**Evidence the check emits:** Page URLs whose `ogDescription` is missing or empty.

**Kind of change that flips it:** Set `og:description` from an existing meta description when one exists. Do not invent copy.

**Depends on:** `—`

This ID has a **script** handler: `seo-geo-remediate <crawl.json> --profile site.yaml --id OG-002`. It reuses `metaDesc` as `og:description` and refuses to invent text when both are empty. Paste the artifact into the page / template, then re-crawl.

Apply the change in the site's own repo or CMS. Re-crawl, confirm the
verdict flipped, then run `seo-geo-plan-sync` so the row is deleted.
Do not hand-edit a generated report.
