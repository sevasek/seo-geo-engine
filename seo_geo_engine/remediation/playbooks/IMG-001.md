# IMG-001 — Every page carries at least 3 supporting images beyond the site logo.

**Rule:** Every page carries at least 3 supporting images beyond the site logo.

**Evidence the check emits:** Pages whose `imageCount` is under the threshold.

**Kind of change that flips it:** Add real supporting images (photos, diagrams) — not decorative 1×1 pixels or the logo repeated.

**Depends on:** `CMS-ACCESS`

The check counts `<img>` elements. Background-image CSS does not count. Alt text is IMG-002; do both.

Apply the change in the site's own repo or CMS. Re-crawl, confirm the
verdict flipped, then run `seo-geo-plan-sync` so the row is deleted.
Do not hand-edit a generated report.
