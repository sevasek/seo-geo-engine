# OG-001 — No page has duplicated `og:title`, `og:url`, or `og:type` tags.

**Rule:** No page has duplicated `og:title`, `og:url`, or `og:type` tags.

**Evidence the check emits:** Page URL plus which of `og:title` / `og:url` / `og:type` appear more than once (`dupOgTags`).

**Kind of change that flips it:** Leave exactly one of each core tag. Duplicate tags usually mean a plugin and the theme both emit OG.

**Depends on:** `CMS-ACCESS`

Find the two emitters (theme vs plugin vs hardcoded `<meta property="og:…">`) and keep one. Do not 'fix' this by deleting all OG tags — OG-002 still requires `og:description`.

Apply the change in the site's own repo or CMS. Re-crawl, confirm the
verdict flipped, then run `seo-geo-plan-sync` so the row is deleted.
Do not hand-edit a generated report.
